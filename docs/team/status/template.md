# Owner handoff template

Owner: replace with your name.
Updated: record an ISO timestamp with timezone.
Baseline: record the main commit inspected.
Branch and PR: link the published branch and PR, or state not published.
Availability: proposed, on branch, or merged.
Tested commit: record the exact commit, or state not tested.

## Current result

Describe what a teammate can actually use and where it lives.
Separate verified behavior from intended behavior.

## Runtime evidence

State unverified, simulated, or live-verified for each integration.
List the checks run, outcomes, and evidence links without secrets.

## Contracts and dependencies

Name the contract version and changed records or endpoints.
List required PRs or commits and whether they are merged.
State what you need from each owner and what each consumer must change.

## Next step and blockers

Name the next concrete action and any blocking dependency with its owner.
If nothing blocks progress, say so after checking.
