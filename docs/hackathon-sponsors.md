# Hackathon sponsor context

Tony supplied this sponsor list on 2026-11-07 and asked that it be remembered when planning the project.
The event is the [YC and Naive Autonomous Company Hackathon](https://events.ycombinator.com/naive-autonomous-companies-hackathon).
The descriptions below summarize Tony's supplied context and were not independently verified in this update.
The account evidence and Tony's later team-credit confirmation are recorded below.
Credits do not establish that an integration works.

## Sponsors

- [OpenAI](https://openai.com) provides GPT models and AI services.
- [HubSpot](https://www.hubspot.com) provides CRM, marketing, sales, and customer-service tools.
- [Stripe](https://stripe.com) provides payment infrastructure and financial APIs.
- [Vercel](https://vercel.com) provides web application deployment and hosting.
- [OpenRouter](https://openrouter.ai) provides access to models from multiple providers through one API.
- [AgentMail](https://agentmail.to) provides email inbox APIs for agents.
- [Luxor](https://luxor.tech) provides GPU compute and AI infrastructure.
- [Monid](https://monid.ai) provides access to agent tools and APIs through one integration with usage-based pricing.
- [Apify](https://apify.com) provides web scraping and automation tools.
- [Mobilerun](https://mobilerun.ai) provides agent control of Android and iOS phones.
- [Render](https://render.com) provides hosting for services, workers, and databases.
- [Neon](https://neon.com) provides serverless Postgres with branching and autoscaling.

## How to use this context

Consider sponsor tools when selecting models, supplier research, external actions, email, payments, hosting, and storage.
Verify the exact capabilities, account access, and any hackathon benefits before choosing an integration.
Use sponsors where they fit the agreed workflow rather than expanding the demo to include every sponsor.
No provider or technology selection is made by this list.
